# Chrome Web Store Screenshot Guide — SuiteMigrate v1.1.3

Use **real screenshots from the exact v1.1.3 release candidate**. Do not hardcode fake extension states, composite unsupported features, or use mock data that implies functionality the submitted package cannot perform.

## Required format

- 1280 × 800 recommended
- PNG or JPEG
- Up to 5 screenshots
- At least 1 screenshot required
- Remove real customer names, emails, account identifiers and confidential source code

## Recommended screenshots

### 1. Successful account scan

Show the extension after scanning the dedicated NetSuite Sandbox reviewer account.

Visible:
- active test account
- total active scripts
- scripts needing migration
- scripts already on 2.1

### 2. Scripts to migrate

Show a real list containing the reviewer test scripts:
- SuiteScript 1.0
- SuiteScript 2.0 or 2.x
- SuiteScript 2.1
- one no-file example

Show the actual Search / Update / All / Done controls and Convert / No file states.

### 3. Successful conversion — Code

Convert the dedicated test script and show the real Code view.

Use a test script created specifically for Store review. Do not expose confidential customer source.

### 4. Changes / Inline review

Show the real Changes or Inline view from the same conversion, including manual-review markers when present.

### 5. HTML migration audit report

Use only if the HTML audit report works correctly in the exact v1.1.3 paid reviewer account.

## Before uploading

- Screenshot comes from v1.1.3
- Feature shown exists in the submitted ZIP
- No passwords, session tokens, API keys or private customer code
- No Team, Batch, ZIP, PDF, Priority Queue or automatic deployment claims
- No “100% accurate”, “production-ready”, or Oracle/NetSuite affiliation claim
- Text remains readable at thumbnail size
